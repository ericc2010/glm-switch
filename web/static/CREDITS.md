# Visual system credits

The dashboard's look comes from the "Spark Performance Dyno" design packet v1.0 (24 October 2026): theme tokens
(`styles/tokens.css`), the SVG gauge renderer (`components/gauges.js`), the brand mark, and the layout the page
adapts. Fonts: Barlow, Barlow Condensed and IBM Plex Mono under the SIL Open Font License 1.1 (`fonts/OFL-*.txt`,
sources in `fonts/sources.json`). The fonts load locally; the page needs no internet.
