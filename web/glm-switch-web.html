Requests

ClientStateSince requestSent

Waiting means no reply has been sent yet: the request is in its prompt (prefill), queued, or is a non-streaming request that is still being answered; a very long prompt can take minutes. Gone means the client already hung up but its request still holds a slot. Drop closes that client's connection and the server cancels its request within seconds; the others keep going. The client sees an error and may send it again.

Unstick

Try them in this order. Drop all frees every slot in seconds without reloading the model. If a dropped request still counts as running after about 30 s, the server is stuck below the point where it checks for cancels: Restart model reloads the same weights (about 2–3 min, every request is cut off, Atlas uses the cloud meanwhile). Capture diagnostics first, while it is stuck: it saves the metrics, connections and every Spark's logs for a look afterwards.
