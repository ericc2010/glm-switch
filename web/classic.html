What the states mean

Waiting means no reply has been sent yet: the request is in its prompt (prefill), queued, or is a non-streaming request still being answered; a very long prompt can take minutes. The cables between the Sparks tell the difference: prompt loading means the prompt is being read (about 2.3 GB/s), engine stalled means nothing has moved for 30 s with work held. Gone means the client already hung up but its request still holds a slot.

Drop closes that client's connection and the server cancels its request within seconds; the others keep going. The client sees an error and may send it again.

Unstick

In this order: capture diagnostics while it is stuck, drop all, and only then restart.

What each one does

Drop all frees every slot in seconds without reloading the model. If a dropped request still counts as running after about 30 s, the server is stuck below the point where it checks for cancels: Restart model reloads the same weights (about 2–3 min, every request is cut off, Atlas uses the cloud meanwhile). Capture diagnostics saves the metrics, connections and every Spark's logs for a look afterwards; take it first, while it is stuck.
